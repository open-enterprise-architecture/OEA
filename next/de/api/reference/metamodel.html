Create new metatype ​

POST /metamodel/metatypes · createMetatype

Creates a metatype with scope=organization in the instance configuration (US-032) or in a solution extension (configId, US-037). A name already used in the instance or in the same extension, compared case-insensitively, gives 409 with problem type urn:oea:problem:name-taken; so does a new instance metatype whose name an extension uses. The base type and the allowed sources and targets of a metatype in an extension are metatypes of the instance or of the same extension; those of an instance metatype are instance metatypes (422). The instance metatypes need metamodel:write, those of an extension solution-metamodel:write. A configuration in import-only gives 403 metamodel-locked (US-035).

Zugriff: eine der Berechtigungen metamodel:write, solution-metamodel:write; zusätzlich metamodel:write, wenn: the metatype belongs to the instance configuration (MetatypeWrite.configId on creation); zusätzlich solution-metamodel:write, wenn: the metatype belongs to a solution extension (MetatypeWrite.configId on creation)
