Dashboards ​

Operationen des Tags Dashboards, die dieses Release implementiert. Erzeugt aus api/openapi.yaml; geplante Operationen sind nicht aufgeführt. Die Beschreibungen stammen aus dem englischen API-Vertrag.

Dashboard overview (US-055, SCR-056) ​

GET /dashboards · listDashboards

The shared dashboards and the caller's own personal dashboards, ordered by name (case-insensitive). Holders of settings:manage also see the personal dashboards of other persons, marked by their owner and not changeable (ADR-032 amendment 2026-11-18). Service accounts get 403.

Zugriff: Berechtigung entity:read

Create a dashboard (US-055, US-062, REQ-051) ​

POST /dashboards · createDashboard

Creates a dashboard without widgets. Scope instance additionally requires dashboard:manage; scope personal needs only entity:read. The name is unique among the shared dashboards and among the personal dashboards of one owner, compared case-insensitively after trimming, and stored trimmed. Writes the audit event dashboard.created. Service accounts get 403.

Zugriff: Berechtigung entity:read; zusätzlich dashboard:manage, wenn: body field scope is 'instance'

Change name, description and scope of a dashboard (US-055, US-062) ​

PUT /dashboards/{id} · updateDashboard

Shared dashboards are changed with dashboard:manage, personal dashboards by their owner only. The owner holding dashboard:manage may change the scope to instance unless a widget shows a personal catalog (422 naming scope); a shared dashboard does not become personal (422 naming scope). Another person's personal dashboard is answered with 404, for holders of settings:manage with 403. Needs If-Match; writes dashboard.updated.

Zugriff: Berechtigung entity:read; zusätzlich dashboard:manage, wenn: the dashboard has scope 'instance', or body field scope changes it to 'instance' (a personal dashboard is changeable by its owner only; another person's personal dashboard is never changeable)

Add a widget (US-058, US-059, REQ-052) ​

POST /dashboards/{id}/widgets · addDashboardWidget

Adds a text, table, KPI or chart widget, up to 50 per dashboard. A KPI or chart widget needs a valid property aggregation (422 naming metatypeId, propertyDefId, function or groupBy); fields of another widget type are rejected with 422 naming the field. A table widget needs a catalog visible to the writer (403 otherwise, also for an unknown catalog), on a shared dashboard a shared catalog (422 naming catalogId), and a saved view of that catalog (422 naming savedViewId). Rights as updateDashboard. Needs If-Match; writes dashboard.updated.

Zugriff: Berechtigung entity:read; zusätzlich dashboard:manage, wenn: the dashboard has scope 'instance' (a personal dashboard is changeable by its owner only; another person's personal dashboard is never changeable)
