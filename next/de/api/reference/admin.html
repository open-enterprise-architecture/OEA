The visibility of every property definition that is not retired, ordered by name, with its translated label and the metatypes that map it today (US-124, REQ-124). Only security administration reads it (visibility:configure, REQ-161).

Update property visibility (SCR-032) ​

PUT /admin/property-visibility · updatePropertyVisibility

Changes the visibility of the listed property definitions in one transaction (US-124, REQ-124, REQ-161); properties not listed stay unchanged. Rules per entry: role-restricted needs at least one read role and every write role must be a read role; connection-scoped needs a connection metatype as scopingConnectionType; the fields of the other modes must be empty; roles must exist. An invalid entry answers 422 with invalidFields such as [1].readRoles and changes nothing; an unknown, retired or repeated property is [i].propertyDefId. A changed property gets a new version and the audit event visibility.changed, flagged as self-benefiting when it adds a role the acting person holds (SoD-6). The answer lists the changed entries.

Zugriff: Berechtigung visibility:configure

Deactivate the local system admin account (US-019) ​

Import metamodel package (ADR-026) ​

POST /admin/metamodel/import · importMetamodelPackage

Imports a metamodel package (e.g. ArchiMate 3.2 base metamodel) into the instance configuration in one transaction (REQ-114). merge: adds new metatypes and properties with scope=imported, updates content the same package imported before; content of another package or with scope organization/built-in is never overwritten (409). replace is not supported yet (422). The body is limited to the configured maximum size (413) and validated against the package schema; a faulty package is rejected with 422 and the location of the first problem (REQ-184). Every import is audited with one batch ID.
