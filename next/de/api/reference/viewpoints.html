Viewpoints ​

Operationen des Tags Viewpoints, die dieses Release implementiert. Erzeugt aus api/openapi.yaml; geplante Operationen sind nicht aufgeführt. Die Beschreibungen stammen aus dem englischen API-Vertrag.

List viewpoints (US-090, SCR-031) ​

GET /admin/viewpoints · listViewpoints

All viewpoints, ordered by name (case-insensitive), with their allowed metatypes and connection types, notation, mappings and origin (system-defined or user-defined).

Zugriff: eine der Berechtigungen entity:read, viewpoint:manage

Create a viewpoint (US-090, UC-12) ​

POST /admin/viewpoints · createViewpoint

Creates a user-defined viewpoint with a name, an optional description, at least one element metatype, any number of connection metatypes of the instance configuration, a notation (default generic) and an optional notation mapping (US-090, US-091). Count, key length, sizes and the visual hint are contract checks (400). Writes viewpoint.created with the notation.

Zugriff: Berechtigung viewpoint:manage

GET /admin/viewpoints/notations · listNotationElements

The elements of the shipped element catalog: ArchiMate 3.2, the component and class elements of UML, the core elements of BPMN 2.0 and the generic elements, each with key, notation, label, kind and default size, ordered by notation and key. Static data of the release; it holds nothing of the instance. The literal path takes precedence over /admin/viewpoints/{id}.

Update a viewpoint (US-090, UC-12 A1) ​

PUT /admin/viewpoints/{id} · updateViewpoint

Replaces name, description, the allowed types, the notation and the mappings with the checks of the creation; a new notation must not keep elements of the old one (422 mappings). Requires If-Match with the version read. A system-defined viewpoint is read-only (422 urn:oea:problem:read-only-viewpoint, US-092 AC1). Writes viewpoint.updated with the notation and the changed fields (notation and mappings among them, without their values).

Zugriff: Berechtigung viewpoint:manage

Delete a viewpoint (US-090 AC3, US-093, UC-12 A2) ​

DELETE /admin/viewpoints/{id} · deleteViewpoint

Requires If-Match with the version read. A system-defined viewpoint is read-only (422 urn:oea:problem:read-only-viewpoint, US-092 AC1). The diagrams of the viewpoint are removed for good in the same transaction, the deleted ones included, each audited as diagram.deleted with the cause viewpoint-deleted; the entities stay. A rejected deletion deletes no diagram. Writes viewpoint.deleted with the notation.

Zugriff: Berechtigung viewpoint:manage
