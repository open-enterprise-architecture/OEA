Diagrams ​

Operationen des Tags Diagrams, die dieses Release implementiert. Erzeugt aus api/openapi.yaml; geplante Operationen sind nicht aufgeführt. Die Beschreibungen stammen aus dem englischen API-Vertrag.

List diagrams (US-074, UC-10, SCR-067) ​

GET /diagrams · listDiagrams

The diagrams that are not deleted, ordered by name (case-insensitive), then by ID, in pages of 1 to 200 (default 50). q keeps the diagrams whose name contains it, case-insensitively and literally (% and _ are no wildcards). A pageSize outside 1-200, a page below 0, a q over 200 characters, and a cursor of another query, a changed cursor or one without page answer 400, the last naming cursor. Read only, not audited.

Zugriff: Berechtigung entity:read

cursorqueryneinstringThe nextCursor of the previous page, sent together with page set to that page's number + 1 (REQ-071). The page then starts after the last row of the previous one instead of skipping rows. The cursor is valid only for the same query (catalog, columns or view, sort, join modes, filters, page size) and only until the backend restarts or the catalog changes; otherwise the query is answered with 400 cursor and the client repeats it without the cursor.

Create a diagram (US-074, UC-10 step 1) ​

POST /diagrams · createDiagram

Creates an empty diagram with version 1 for an existing viewpoint. The name is trimmed, has 1 to 200 characters and is unique among the diagrams, ignoring case (urn:oea:problem:diagram-name-taken, 422 naming name); the description has at most 2000 characters. An unknown or missing viewpoint, a blank or over-long name and an over-long description answer 422 naming the field. Persons and service accounts with entity:write create diagrams and are their creator; the local system admin account has no person and gets 403. Writes the audit event diagram.created.

Zugriff: Berechtigung entity:write

Restore a deleted diagram (US-074, SCR-067) ​

POST /diagrams/{id}/restore · restoreDiagram

Clears the deletion of the diagram and raises the version; it is listed again and its navigation tree entries show again. Needs If-Match with the version of the deleted diagram (428 without, 412 when stale). An unknown diagram answers 404, one that is not deleted 409 (urn:oea:problem:diagram-not-deleted), and a name that an active diagram has meanwhile 422 urn:oea:problem:diagram-name-taken naming name. Writes diagram.restored.

Zugriff: Berechtigung entity:restore

Delete a diagram (US-074) ​

DELETE /diagrams/{id} · deleteDiagram

Marks the diagram as deleted (US-074, owner decision 2026-11-19): it is no longer listed, counted or readable (404), its name is free again, and its entries in the navigation tree are left out until it is restored with restoreDiagram. The entities of the repository stay. Needs If-Match; raises the version. Writes diagram.deleted. Deleting a viewpoint removes its diagrams for good, the deleted ones included.
