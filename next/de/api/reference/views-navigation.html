Views – Navigation ​

Operationen des Tags Views – Navigation, die dieses Release implementiert. Erzeugt aus api/openapi.yaml; geplante Operationen sind nicht aufgeführt. Die Beschreibungen stammen aus dem englischen API-Vertrag.

Navigation tree (US-054, SCR-055, SCR-010/011) ​

GET /views/explorer · getExplorerView

The navigation tree from the root folder "Repository", with all folders and their catalog entries (US-054, REQ-050, REQ-095). Folders and entries are sorted by name regardless of case, an entry by its display label if set. An entry on another person's personal catalog and an entry whose catalog no longer exists are left out.

Zugriff: Berechtigung entity:read

Create a folder in the navigation tree (REQ-094, UC-13) ​

POST /tree-nodes · createTreeNode

Creates a folder under an existing folder. The name is trimmed, has 1–255 characters without control characters and is unique among its siblings regardless of case (BR-01). A folder is at most 10 levels below the root; the tree has at most 500 folders. Validation errors answer 422 with invalidFields name or parentId (an unknown parent). Writes the audit event tree-node.created.

Zugriff: Berechtigung viewpoint:manage

Request-Body ​

  • application/json: TreeNodeCreate

Place a catalog in a folder (US-054, REQ-050, REQ-097) ​

POST /tree-nodes/{nodeId}/items · addTreeNodeItem

Places a catalog in the folder, with an optional display label of at most 255 characters. A catalog may be placed in several folders, but only once per folder (BR-06). A second entry in the same folder and a catalog the caller cannot see answer 422 with invalidFields referenceId; a folder has at most 200 entries. An unknown folder answers 404. Writes the audit event tree-node.item-added.

Zugriff: Berechtigung viewpoint:manage
