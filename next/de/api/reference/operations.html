Operations ​

Operationen des Tags Operations, die dieses Release implementiert. Erzeugt aus api/openapi.yaml; geplante Operationen sind nicht aufgeführt. Die Beschreibungen stammen aus dem englischen API-Vertrag.

Liveness and readiness of the instance (REQ-075) ​

GET /health · getHealth

Public, because orchestrators and load balancers probe it without credentials. Returns only the aggregated status – no component details, versions or instance data.

Zugriff: öffentlich – ohne Anmeldung
