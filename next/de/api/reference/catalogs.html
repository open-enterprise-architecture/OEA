GET /catalogs · listCatalogs

Create a catalog (US-046, REQ-043) ​

POST /catalogs · createCatalog

Creates a catalog without columns, joins, saved filters and saved views. A catalog with scope instance additionally requires catalog:manage (ADR-032 §3); a catalog with scope personal is visible only to its creator. The name is unique within the instance across both scopes, compared case-insensitively after trimming, and stored trimmed. Writes the audit event catalog.created.

Zugriff: Berechtigung entity:read; zusätzlich catalog:manage, wenn: body field scope is 'instance'

Query a catalog (US-049, REQ-046, SCR-020) ​

GET /catalogs/{id}/query · queryCatalog

One page of rows: the active entities of the catalog's primary metatype with the values of the catalog's columns. Until columns can be configured (US-047), the columns are name and, if the primary metatype maps a property named Status with visibility public, that property. Only properties with visibility public appear (REQ-160 follows). Soft-deleted entities are not returned (ADR-019).

sort accepts exactly one {column}:{asc|desc} pair whose column is a key of columns. Without sort the rows are ordered by name ascending; rows without a value in the sort column come last. Sorting applies before paging; a page beyond the last one answers with no rows. A personal catalog of another person is answered with 404, like a catalog that does not exist (ADR-032 §8 L3).

Zugriff: Berechtigung entity:read
