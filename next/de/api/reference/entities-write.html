Entities – Write ​

Operationen des Tags Entities – Write, die dieses Release implementiert. Erzeugt aus api/openapi.yaml; geplante Operationen sind nicht aufgeführt. Die Beschreibungen stammen aus dem englischen API-Vertrag.

Create/update entities and connections in batch ​

POST /entities/batch · batchWriteEntities

Writes up to 500 entities and 500 connections in one request. The preferred endpoint for external systems with strategy: upsert (ADR-026). ?dryRun=true → validation without persisting. Connections are written after the entities; their endpoints are checked against the connection metatype (codes SOURCE_REQUIRED, SOURCE_AMBIGUOUS, SOURCE_NOT_FOUND, SOURCE_NOT_ALLOWED, the same for TARGET_, METATYPE_NOT_CONNECTION and ENDPOINT_CHANGE_NOT_SUPPORTED). An update of an entity with an open issue of a solution fails with OPEN_ISSUES (US-153 AC1). Not supported yet: dryRun=true (US-141 AC3) is rejected with 422; parentId and lifecycle are item errors. X-Agent-Id is stored only as the informational audit field agent_label (ADR-033 §7). A batch with a connection of a metatype that is the scopingConnectionType of a property definition needs visibility-scope:assign; without it the whole batch is rejected with 403 (REQ-161). A value of a role-restricted property, set or removed, needs one of its write roles, and a value of a connection-scoped property an existing entity in the writer's scope; otherwise the whole batch is rejected with 403 (REQ-126, REQ-127). A property not named keeps its value.

Zugriff: Berechtigung entity:write; zusätzlich visibility-scope:assign, wenn: a connection of a type used as scopingConnectionType is written

Create connection between two entities ​

POST /connections · createConnection

Creates a connection, an entity of a connection metatype with a source and a target (US-036, ADR-010). Source and target are referenced by internal ID or externalId; their metatypes must be allowed by the connection metatype (subtypes included) and cannot change afterwards. Without name the connection is named <source name> → <target name>. Properties are checked as for entities. A connection of a metatype that is the scopingConnectionType of a property definition also needs visibility-scope:assign, otherwise 403 (REQ-161). A value of a role-restricted property needs one of its write roles, otherwise 403 (REQ-126); a value of a connection-scoped property cannot be set on creation, because the connection is not yet in the writer's scope (403, REQ-127).

Zugriff: Berechtigung entity:write; zusätzlich visibility-scope:assign, wenn: a connection of a type used as scopingConnectionType is written

Set or clear the parent of an element entity (US-135, UC-13) ​

PUT /entities/{id}/parent · setEntityParent

Places an element entity under another element entity, or clears the parent with parentEntityId: null (US-135, US-136; REQ-141, REQ-142, ADR-021). The change is versioned like other entity changes: it writes the next version of the child, whose history, versions and diffs show the system field parentEntityId ("Parent") by name, and the audit event entity.parent-changed; the parent keeps its version. A restore does not restore the parent. Setting the parent the entity already has changes nothing and writes no version and no event (composition.reason unchanged).

The parent is another element entity that is not deleted; connections have no parent and are no parent. A parent that is the entity itself, one of its descendants, a connection, deleted or unknown, or a subtree that would end more than 10 levels below the root (the root level is level 1) gives 422 naming parentEntityId; a connection as child gives 422 naming entityId.

When neither entity is a structuring aid and the connection metatype marked as composition (isComposition) allows the metatype of the parent as source and that of the child as target, a connection of it from the parent to the child is created in the same transaction and marked autoCreated; otherwise only the parent is stored and composition.reason says why. Clearing or changing the parent soft-deletes the connection auto-created for the previous parent (removedConnectionId), if it is not deleted yet; a connection written by other means stays.

If-Match with the current version of the child is required: 428 without it, 412 stale-version when the entity changed meanwhile. An entity with an open issue of a solution gives 409 entity-blocked (US-153). Needs entity:write.

Zugriff: Berechtigung entity:write

Create a structuring aid (US-136, UC-13) ​

POST /structuring-aids · createStructuringAid

Creates a structuring aid, a purely navigational grouping (US-136, REQ-141): an entity of the built-in metatype "Structuring aid" with isStructuralGrouper set, at the root level or under parentEntityId. It has no properties, no connections and is not part of a solution. The name is trimmed and has 1–255 characters, the description at most 2000. The parent is checked as for setEntityParent (an element entity that is not deleted, at most 10 levels deep); an invalid one gives 422 naming parentEntityId, an invalid name or description 422 naming name or description; a parentEntityId below 1 gives 422 naming parentEntityId too. Writes version 1 and the audit event entity.created. Needs entity:write.

Zugriff: Berechtigung entity:write

Delete a structuring aid (US-136, UC-13) ​

DELETE /structuring-aids/{id} · deleteStructuringAid

Soft-deletes a structuring aid (ADR-019). Its children move to the root level, each with a new version (entity.parent-changed), and none of them is deleted; the aid is deleted with the audit event entity.deleted (cause structuring-aid-deleted), all in one transaction. An entity that is no structuring aid gives 422 naming entityId. If-Match with the current version of the aid is required (428, 412). The aid or one of its children with an open issue of a solution gives 409 entity-blocked. Needs entity:write and entity:delete.

Zugriff: Berechtigung entity:write, entity:delete
