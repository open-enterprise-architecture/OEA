Entities – Write ​

Operationen des Tags Entities – Write, die dieses Release implementiert. Erzeugt aus api/openapi.yaml; geplante Operationen sind nicht aufgeführt. Die Beschreibungen stammen aus dem englischen API-Vertrag.

Create/update entities and connections in batch ​

POST /entities/batch · batchWriteEntities

Writes up to 500 entities and 500 connections in one request. The preferred endpoint for external systems with strategy: upsert (ADR-026). ?dryRun=true → validation without persisting. Connections are written after the entities; their endpoints are checked against the connection metatype (codes SOURCE_REQUIRED, SOURCE_AMBIGUOUS, SOURCE_NOT_FOUND, SOURCE_NOT_ALLOWED, the same for TARGET_, METATYPE_NOT_CONNECTION and ENDPOINT_CHANGE_NOT_SUPPORTED). Not supported yet: dryRun=true (US-141 AC3) is rejected with 422; parentId and lifecycle are item errors. X-Agent-Id is stored only as the informational audit field agent_label (ADR-033 §7).

Zugriff: Berechtigung entity:write; zusätzlich visibility-scope:assign, wenn: a connection of a type used as scopingConnectionType is written

Create connection between two entities ​

POST /connections · createConnection

Creates a connection, an entity of a connection metatype with a source and a target (US-036, ADR-010). Source and target are referenced by internal ID or externalId; their metatypes must be allowed by the connection metatype (subtypes included) and cannot change afterwards. Without name the connection is named <source name> → <target name>. Properties are checked as for entities.

Zugriff: Berechtigung entity:write; zusätzlich visibility-scope:assign, wenn: a connection of a type used as scopingConnectionType is written
