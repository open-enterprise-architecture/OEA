Create a solution in project mode (US-038, REQ-038) ​

POST /solutions · createSolution

Creates a solution with status draft; the caller becomes owner and creator, and fromPlateauId and toPlateauId stay null (project mode; plateau mode follows in S14). The name is unique within the instance, compared case-insensitively after trimming, and stored trimmed. Only persons create solutions; the local system admin account gets 403. Writes the audit event solution.created.

Baseline of a solution (US-039, SCR-061) ​

GET /solutions/{id}/landscape · getSolutionLandscape

The current IT landscape the solution builds on. In project mode these are the entities of element metatypes that are not deleted (owner decision 2026-11-12), ordered by name (case-insensitive), then by ID. q searches a part of the name, case-insensitively; metatypeId keeps the entities of one metatype, and an unknown metatype gives an empty page. A cursor of another query, a changed cursor or one without page answers 400 naming cursor.

Capture an entity delta (US-040, US-042, REQ-040) ​

POST /solutions/{id}/deltas · createSolutionDelta

Captures a delta new (a proposed entity with its property values, checked like the write of a new entity; no entity is written before the go-live), modified (changes of an entity of the baseline, checked like its update; the server records the before values, and a delta without any change answers 422) or retiring (an entity of the baseline). A solution holds one delta per entity, and a new delta per metatype and name (case-insensitive), and any number of deltas. A value of a role-restricted property needs a write role, and a connection-scoped value cannot be set (403). Any holder of solution:write captures deltas, in any solution. Writes the audit event solution.delta-added. The response names the other active solutions that change the same entity (conflicts, US-044); a conflict never rejects the delta.

Zugriff: Berechtigung solution:write
