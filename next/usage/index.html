On this page
This manual describes the unreleased development state of OEA (main).

Usage ​

  • Logging in: log in through your identity provider or with the local system admin account, set up a second factor and look at your profile
  • Catalogs: create a catalog and browse its entities in a table
  • Writing entities in batch: create and update entities from a source system through the API

What you see and may do depends on your roles. If a page tells you that you have no access, ask an administrator for a role (see Roles and permissions).
