Create property mapping ​

POST /metamodel/metatypes/{id}/property-mappings · createPropertyMapping

Maps an organization property definition to any metatype, also an imported or built-in one. A property already mapped in the base type chain of the metatype or its subtypes gives 409 urn:oea:problem:conflict; a package definition gives 409 read-only-metatype. For a property already mapped to this metatype – also a package mapping – the request adds an entry by effective date (US-137, ADR-049): the entry with the latest validFrom not after today applies, earlier entries stay; the same date twice gives 409 urn:oea:problem:conflict. A date in the past takes effect at once, a future one when the date is reached (markedEntityCount is then 0). A mandatory mapping marks every existing entity of the metatype and its subtypes without a value (markedEntityCount); such an entity is rejected when written again without the value. Changing the necessity by effective date follows (US-137).
