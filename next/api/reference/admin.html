Deactivate the local system admin account (US-019) ​

POST /admin/system-admin-account/deactivate · deactivateSystemAdminAccount

Revokes the account's sessions and ends its password login; IdP logins are not affected. Rejected with 409 and problem type urn:oea:problem:last-admin-path if no other usable path to system-admin remains (ADR-032 SoD-7): an active, approved, not deleted IdP group mapping to system-admin of an enabled provider that has matched at least once (lastMatchedAt). An already deactivated account is answered with 200 unchanged. Audited as system-admin-account.deactivated (outcome success or denied).

PUT /admin/settings/password-policy · updatePasswordPolicy

Replaces the stored policy; read-only fields are ignored. Applies to every password set afterwards and to the expiry check at the next login. Rejected with 422 and invalidFields naming each offending field if a value is below an operator floor, the minimum length is shorter than the number of required character types (REQ-028 AC4), or personPasswordLogin is true while the operator does not permit it. Import metamodel package (ADR-026) ​

POST /admin/metamodel/import · importMetamodelPackage

Imports a metamodel package (e.g. ArchiMate 3.2 base metamodel) into the instance configuration in one transaction (REQ-114). merge: adds new metatypes and properties with scope=imported, updates content the same package imported before; content of another package or with scope organization/built-in is never overwritten (409). replace is not supported yet (422). The body is limited to the configured maximum size (413) and validated against the package schema; a faulty package is rejected with 422 and the location of the first problem (REQ-184). Every import is audited with one batch ID.
