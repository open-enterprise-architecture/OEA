Set the initial password of a person (US-023, REQ-024) ​

POST /admin/persons/{personId}/password · setInitialPassword

Only while the operator has switched on password login of persons. Stores the password as argon2id with origin initial; it expires after oea.auth.temporary-password-validity (default 72 h) and must be changed at the first login (REQ-173 AC1/AC2). The password is never returned or logged. Audited as person.password-set.

  • Person already has a password → 409 with problem type urn:oea:problem:password-already-set; password login of persons off → 409 (conflict)
  • Own person → 403 with reason: self-administration (SoD-1)
  • Service account, person not invited/active, or a password outside 12–128 characters → 422

Change the status of a person (UC-23 A2, US-148) ​

POST /admin/persons/{personId}/status · changePersonStatus

Transitions active ⇄ inactive and invited/active/inactive → offboarded. Leaving active or invited revokes all sessions of the person at once (REQ-164); offboarded also revokes every local role assignment (audited as role.revoked), while inactive keeps them. Audited as person.status-changed.

  • Own status → 403 with reason: self-administration (SoD-1)
  • Another transition, an unchanged status, or offboarded → invited while the reactivation of offboarded persons is off → 409 with problem type urn:oea:problem:invalid-status-transition
  • Last usable path to system-admin → 409 with problem type urn:oea:problem:last-admin-path (SoD-7)
  • Service account → 422 (status changes of service accounts follow with US-142)
