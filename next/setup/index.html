Setup and first steps ​

To get a working instance, you go through three steps:

  1. Installation: start PostgreSQL, the migration step and the backend with Docker Compose, or prepare your own PostgreSQL.
  2. First administrator: create the local system admin account with the one-time setup token and secure it with a second factor.
  3. Continue with the Administration: connect your identity provider, grant roles and import the starter configuration.
