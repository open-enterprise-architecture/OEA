# Setup and first steps

To get a working instance, you go through three steps:

1. [Installation](./installation): start PostgreSQL, the migration step and the backend with Docker Compose, or prepare your own PostgreSQL.
2. [First administrator](./first-administrator): create the local system admin account with the one-time setup token and secure it with a second factor.
3. Continue with the [Administration](../administration/): connect your identity provider, grant roles and import the starter configuration.
