# Business Rules (cross-object)

Business rules that go beyond a single business object. One file per rule with the schema `BR-NN-name.md`.

Object-specific rules are maintained directly in the respective business object as a section.

## Format

- Rule ID (BR-NN)
- Statement in natural language
- Formal statement (if possible, e.g. JSON Logic, OCL)
- Trigger (event, state)
- Affected business objects
- Compliance reference (e.g. GDPR Art. 6, FINMA circular)
- Examples
